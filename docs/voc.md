# Year 2 Australian Vocabulary List

This is a practical list of common words many children are expected to understand by the end of Year 2 in Australia. Meanings use simple words and each word has a short sentence.

| Word | Meaning | Example Sentence |
|------|---------|------------------|
| about | on the subject of | We talked about birds. |
| above | higher than | The bird flew above us. |
| across | from one side to another | We walked across the road. |
| action | something you do | Running is an action. |
| afraid | feeling scared | I was afraid of the storm. |
| after | later than | We played after lunch. |
| again | one more time | Please read it again. |
| always | every time | I always brush my teeth. |
| animal | a living creature | The dog is an animal. |
| answer | a reply | I know the answer. |
| arrive | to get somewhere | We arrive at school early. |
| beautiful | very pretty | The flower is beautiful. |
| because | for that reason | I wore a coat because it was cold. |
| before | earlier than | Wash your hands before eating. |
| begin | to start | Let's begin the game. |
| below | lower than | The fish swam below the boat. |
| between | in the middle of two things | The ball is between the cones. |
| borrow | take and return later | I borrow books from the library. |
| brave | showing courage | The brave firefighter helped people. |
| build | to make something | We build with blocks. |
| busy | having a lot to do | Mum is busy today. |
| change | make different | The leaves change colour. |
| climb | go up | I can climb the ladder. |
| clever | good at thinking | She is a clever student. |
| collect | bring together | I collect shells. |
| common | happening often | Colds are common in winter. |
| compare | look for differences and similarities | Compare the two pictures. |
| complete | finished | My homework is complete. |
| country | land where people live | Australia is a country. |
| course | the way something moves | The river changed course. |
| decide | choose | I decide to draw. |
| different | not the same | The twins wear different hats. |
| discover | find something new | We discover insects in the garden. |
| early | before expected time | We arrived early. |
| Earth | the planet we live on | Earth goes around the Sun. |
| enough | as much as needed | We have enough food. |
| enter | go into | Enter the classroom quietly. |
| equal | the same amount | Both teams have equal points. |
| example | something that shows an idea | This is an example. |
| excited | very happy and eager | I am excited for the trip. |
| explain | tell how or why | Can you explain the rule? |
| family | people related to you | My family eats dinner together. |
| favourite | liked the most | Blue is my favourite colour. |
| field | open land | The sheep are in the field. |
| follow | go after | Follow the teacher. |
| forward | toward the front | Take one step forward. |
| friendly | kind to others | Our neighbour is friendly. |
| giant | very large | We saw a giant pumpkin. |
| group | people together | Work in a group. |
| guess | answer without knowing for sure | I will guess the number. |
| habit | something done often | Reading is a good habit. |
| healthy | good for your body | Fruit is healthy. |
| history | things that happened in the past | We learned local history. |
| honest | truthful | Be honest with your teacher. |
| idea | a thought or plan | I have an idea. |
| important | very useful or needed | Water is important. |
| include | have as part of something | The list includes apples. |
| jump | push off the ground | The frog can jump. |
| knowledge | things you know | Reading builds knowledge. |
| language | words used to speak | English is a language. |
| learn | gain knowledge | We learn every day. |
| library | place with books | We visited the library. |
| listen | pay attention to sound | Listen carefully. |
| measure | find out size or length | Measure the desk. |
| minute | a short unit of time | Wait one minute. |
| mountain | very high land | We climbed a mountain. |
| nature | plants and animals | We enjoy nature. |
| notice | see something | Did you notice the bird? |
| number | a counting symbol | Seven is a number. |
| obey | follow rules | We obey school rules. |
| opinion | what someone thinks | That is my opinion. |
| organise | put in order | Organise your pencils. |
| paragraph | a group of sentences | Write one paragraph. |
| patient | able to wait calmly | Be patient in the queue. |
| planet | a large object in space | Mars is a planet. |
| possible | able to happen | It is possible to win. |
| practice | do again to improve | Practice your spelling. |
| predict | make a good guess | Predict what happens next. |
| problem | something difficult to solve | We solved the problem. |
| protect | keep safe | Trees protect animals. |
| question | something you ask | I have a question. |
| quiet | making little noise | Please be quiet. |
| remember | keep in your mind | Remember your hat. |
| respect | treat well | Respect other people. |
| result | what happens in the end | The result was good. |
| science | learning about the world | Science is interesting. |
| search | try to find | Search for the missing sock. |
| sentence | words that make a complete thought | Write a sentence. |
| special | different in a good way | Today is special. |
| strong | having power | The ant is strong. |
| suddenly | quickly and unexpectedly | It suddenly started raining. |
| survive | stay alive | Plants survive with water. |
| symbol | a sign that means something | A heart is a symbol of love. |
| teacher | a person who helps students learn | Our teacher reads stories. |
| travel | go from one place to another | We travel by car. |
| unique | one of a kind | Every fingerprint is unique. |
| value | how important something is | Kindness has value. |
| village | a small town | They live in a village. |
| weather | what the sky is like | The weather is sunny. |
| wonder | think about with interest | I wonder why birds sing. |
| world | Earth and all people and places | We live in the world. |
